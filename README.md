# Simple Interest Calculator

## Description
This project is a simple interest calculator using Bash scripting.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest
- Time period

## Technology Used
- Bash

## How to Run
Execute the `simple-interest.sh` script and enter the principal, rate of interest, and time period when prompted.

## Output
The program calculates and displays the simple interest based on the entered values.
